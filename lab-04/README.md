# Lecture 04 — Advanced Dart and course registration

From this directory, run:

```sh
flutter pub get
flutter analyze
flutter run -d chrome
```

For Android, connect a device or start an emulator, then run flutter devices and flutter run -d DEVICE_ID.

Run `dart run lib/course_registration.dart` for all console exercises. The spread operator combines lists; null-aware spread skips a missing list. Collection-if and collection-for can build widget lists. Student.fromMap and Product.free are named constructors. Functions can be stored and passed to map. The leading underscore limits access to the Dart library. The Logger mixin adds reusable logging. Cascades configure the same object without repeating its name. The Flutter screen includes a named register callback and an anonymous remove callback.
